Cartografía e Infografía de Jardín Botánico Viña del Mar

Este encargo corresponde al proyecto final del Taller de Ciudad Legible de 2024. Durante este ciclo se trabajó en un anteproyecto sobre diseño de Wayfinding en el Museo de Historia Natural de Valparaíso, y posteriormente se trabajó en el proyecto final en el Jardín Botánico.



Anteproyecto

Esta unidad de trabajo se centró en el diseño de infografías y Wayfinding en torno al Museo de Historia Natural de Valparaíso, para esto, el taller recorrió el museo para observar sus sistemas de información, el recorrido diseñado, la manera en la que presenta la información, como se circula, cuales son los puntos de incertidumbre, como es la experiencia y como aparecen las cosas para mostrar un fenómeno.

A partir de todo lo observado y registrado en el recorrido, se procedió a construir un mapa para el museo, tomando en cuenta su colorimetría, carácter educativo, uso de las tipografías, etc., todo esto en una maqueta de folleto que mostrara, por una parte, información del mismo museo, y por otra parte, una infografía sobre un fenómeno elegido por cada estudiante.


Primera Propuesta

En esta primera versión, que solo abarcaba información sobre el museo, se pensó en utilizar una fotografía vectorizada de la fachada del museo como portada para mostrarlo y se intentó darle dinamismo a las fotografías de las exposiciones al inclinarlas en diferentes posiciones.



Segunda Propuesta

Para la segunda propuesta, con el fenómeno a tratar ya decidido, se propuso una idea de diagramación para mostrar la información sobre este, utilizando fotografías, pictogramas, texto falso y un fondo de la marea roja que posteriormente se quitó porque no comunicaba nada y no se estaba utilizando para decir algo sobre él. La la portada se cambió pues la fachada del museo no funcionaba para comunicar lo que contiene, sino más bien su estructura arquitectónica, por lo que se decidió utilizar una fotografía de la Sala Fótica del museo.



Tercera Propuesta

Para la tercera propuesta se decidieron 3 columnas de información para explicar el fenómeno, utilizando ilustraciones y pictogramas, y para el tiro, que mostraba información sobre el museo, se decidió dejar un mapa de este con vista isométrica y los pictogramas de cada zona en sus respectivas exposiciones, utilizando los mismos colores de cada exposición en los bloques de texto que indicaban sus nombres.



Cuarta Propuesta

Tras ver esta la anterior propuesta impresa se decidió, para esta siguiente versión, apagar el tono de casi todas las ilustraciones y del fondo pues los colores se veían muy saturados, además de agregar una ilustración central que diera paso a hablar del fenómeno a partir de ella.



Versión Final

Para la versión final de la infografía se redibujaron todas las ilustraciones, fotografías y pictogramas para que todas las nuevas imágenes formaran parte de un mismo estilo visual, también se quitó el fondo degradado que no aportaba nada y se agregó un fondo tenue que simula las ondas de las mareas del mar. Para la portada se quitó cualquier imagen y se colocó el logo junto al contacto del museo y se volvieron a agregar las fotografías de las exposiciones utilizadas en la primera propuesta, esta vez sin alterar su posición, utilizándolas solamente como un vistazo a lo que ofrece el museo. Para la contraportada, que muestra la zona del mapa, se mantuvo el mismo pero se quitaron los pictogramas, pues perdían su calidad y no se apreciaban bien con el formato carta. Se mantuvieron los pictogramas en los bloques de colores que indican el nombre de cada sala.

Tiro del folleto, parte Museo



Proyecto Final

Durante la última unidad de trabajo, el taller se enfocó en diseñar un mapa e infografía para el Jardín Botánico Nacional de Viña del Mar, diseñando un sistema de pictogramas, un logo y una forma de visualizar lo que el Jardín ofrece para el público y conserva como parque.


La elección del color

Una de las problemáticas principales que se entregó para realizar el trabajo fue la prohibición del uso del color verde, por lo que se debió buscar otro color para la infografía. Lo primero que se realizó antes de comenzar a diseñar todo, fue elegir el color con el que se realizaría todo el trabajo. Naranjo fue el seleccionado pues es uno de los colores utilizados en la página web del Jardín Botánico, y al usar un pliego blanco de base, los colores se complementarían de buena manera en palabras con Bold o bloques naranjos con texto blanco.



Desarrollo de los Pictogramas

Lo primero que se comenzó a diseñar fueron los pictogramas de las atracciones y servicios del Jardín Botánico. Estos se realizaron tras un ejercicio de dibujo previo en el que, una vez elegida una especie botánica del jardín, esta se tendría que dibujar desde lo macro a lo micro, y a partir de estos dibujos, extraer la paleta de trazos que serían utilizados para la construcción del juego de pictogramas. El primer dibujo sería utilizado como base para crear el primer pictograma, del cual se extraerían trazos básicos, como líneas rectas y curvas. Tras haber realizado algunos pictogramas, la primera vez que estos fueron colocados en el mapa, se notó al imprimirlo que el trazo era muy delgado así que se engrosó para que fueran más visibles.



El Logo

Para el primer isologo diseñado se usó la figura de un ganso incrustada en una flor naranja, pero este fue descartado pues daba la imagen al parque de ser un Jardín Zoológico en vez de un Jardín Botánico. Entonces se reemplazó el pato y la flor por el logo original de Jardín que se encuentra en el lugar, el cual se trabajó para darle una forma más definida, mostrando un corazón del que salen un árbol.



Los Mapas

Paralelo a la construcción de los pictogramas también estaban en desarrollo el mapa principal y las vistas de cada extremo del jardín, tomando en cuenta que el Jardín no es una planicie, se quiso visualizar esto graficando cotas de altura en los terrenos elevados del parque. En estas ilustraciones se utilizó el color naranjo para mostrar las atracciones y se pensó en los tonos de naranjo para mostrar aquello que estaba diseñado para que fuera recorrido por los visitantes.

Las primeras propuestas se usaron para visualizar la idea, pues las cotas no eran certeras.



Las colecciones

Para ilustrar las colecciones más importantes destacadas en la página web, se utilizaron fotografías originales intervenidas con ilustraciones naranjas que remarcarían la especie a la que se refiere el título de la colección, manteniendo el fondo en escala de grises y agregando la ilustración de una persona, también en escala de grises, para tener una referencia de escala respecto a la especie.
